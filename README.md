# Superstore Power BI Dashboard

## Project Overview
This project focuses on analyzing Superstore sales data using Power BI. The goal was to build an interactive dashboard that helps users understand sales performance, profit trends, and business insights more clearly.

## Dataset
The dataset includes sales-related information such as:

- Order details
- Sales
- Profit
- Customer information
- Product categories
- Region and location
- Shipping details

## Project Workflow
1. Reviewed the project requirements and business goal
2. Prepared the dataset for reporting
3. Designed a star schema for the data model
4. Built the Power BI dashboard
5. Created visuals to show important KPIs and trends
6. Documented the project findings and process
